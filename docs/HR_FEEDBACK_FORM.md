# Форма обратной связи HR-эксперта

> Заполняется после ручной проверки ATS-анализа Job Fit Copilot. Скопируйте шаблон в свой файл, заполните все поля и отправьте через PR, issue или в Telegram-чат [@jobfitcopilot_chat](https://t.me/jobfitcopilot_chat). YAML-блок в начале обрабатывается автоматически — не меняйте структуру ключей.

---

## Шаблон формы

```markdown
---
feedback_id: 2026-001                # уникальный ID, выдаёт мейнтейнер
date: 2026-11-18                    # дата ревью (YYYY-MM-DD)
expert:
  name: "Иван Иванов"
  tier: basic                        # basic | advanced | partner
  expertise_area: IT                 # IT | Finance | Healthcare | Other
vacancy:
  url: https://hh.ru/vacancy/12345678
  title: "Senior Frontend Developer"
  platform: hh.ru                    # hh.ru | linkedin | upwork | other
ats_analysis:
  skills_match: 78                   # скор AI (0-100)
  experience_match: 65
  education_match: 90
  overall_score: 74
expert_assessment:
  skills_match: 4                    # оценка эксперта (1-5)
  experience_match: 3

  overall_score: 3
verdict: needs_calibration           # agree | minor_deviation | needs_calibration | disagree
---
```

## Описание полей

### YAML frontmatter (машинно-обрабатываемая часть)

| Поле | Тип | Описание |
|---|---|---|
| `feedback_id` | string | Уникальный ID формы, выдаёт мейнтейнер |
| `date` | date | Дата ревью |
| `expert.name` | string | Имя эксперта |
| `expert.tier` | enum | `basic` / `advanced` / `partner` |
| `expert.expertise_area` | enum | `IT` / `Finance` / `Healthcare` / `Other` |
| `vacancy.url` | URL | Ссылка на вакансию |
| `vacancy.title` | string | Название вакансии |
| `vacancy.platform` | enum | `hh.ru` / `linkedin` / `upwork` / `other` |
| `ats_analysis.*` | int 0–100 | Скоры, которые выдала система |
| `expert_assessment.*` | int 1–5 | Оценки эксперта по каждой категории |
| `verdict` | enum | Итоговое суждение (см. ниже) |

### Значения `verdict`

- `agree` — оценки эксперта и AI совпадают.
- `minor_deviation` — небольшие расхождения, не влияющие на решение.
- `needs_calibration` — систематическое расхождение, требуется калибровка весов.
- `disagree` — вывод AI неверен, решение по кандидату противоположное.

### Разделы формы

1. **Вакансия** — URL и контекст проверяемой вакансии.
2. **Оценка ATS-анализа** — таблица со скорами AI и оценками эксперта по шкале 1–5 для каждой категории: совпадение навыков, опыта, образования, итоговый скор.
3. **Качественная обратная связь** — что AI пропустил, что переоценил, что недооценил.
4. **Предложения** — свободный текст по улучшению скоринга и методологии.

### Шкала оценки 1–5

| Балл | Значение |
|---|---|
| 5 | Вывод AI полностью корректен и подтверждён экспертом |
| 4 | В целом верно, есть неточности в деталях |
| 3 | Частично верно, но требуются поправки в весах/логике |
| 2 | Существенные расхождения с экспертным суждением |
| 1 | Вывод AI неверен и вводит в заблуждение |

## Конфиденциальность

- Все резюме предоставляются в обезличенном виде с согласия кандидата.
- Персональные данные кандидатов в формах не публикуются.
- Имя эксперта публикуется только с его согласия (в благодарностях релиза).
