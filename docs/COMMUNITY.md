## Текущее состояние

Job Fit Copilot — Chrome-расширение с открытым исходным кодом для ATS-анализа резюме и оценки соответствия вакансий. Проект находится в активной разработке (v0.6.0), имеет ядро пользователей и HR-экспертную программу на стадии запуска.

## GitHub: рост звёзд и контрибьюция

### Тактика роста звёзд

1. **Quality сигнал:** README с бейджами, скриншотами, чётким позиционированием — уже реализовано.
2. **SEO:** описание проекта на русском и английском, релевантные теги (ATS, resume analyzer, job fit, HR tech).
3. **Social proof:** бейдж «HR Expert Program», ссылки на статьи, цитаты экспертов.
4. **Cross-promotion:** упоминание в смежных open-source проектах, HR-сообществах.
5. **Release notes:** каждое обновление — в CHANGELOG.md + пост в Telegram.

### Как мы привлекаем контрибьюторов

- `good-first-issue` для новых участников (включая HR-экспертные заявки).
- `help-wanted` для задач, где нужна помощь сообщества.
- Чёткий CONTRIBUTING.md с инструкцией по запуску и тестированию.
- Code review с обратной связью на русском языке.

## Community Guidelines

### Для всех участников

1. **Уважение.** Проект открыт для всех независимо от опыта, языка и бэкграунда.
2. **Конструктив.** Критика приветствуется, но с предложениями, а не просто «это плохо».
3. **Прозрачность.** Любые договорённости с мейнтейнером — публично в issues или чате.
4. **Без рекламы.** Чат и issues — не место для продвижения своих продуктов.

### Для HR-экспертов

1. Заполнять форму ревью полностью, не пропуская разделы.
2. Указывать вердикт (`agree` / `minor_deviation` / `needs_calibration` / `disagree`) — это ключевое поле для калибровки.
3. Не разглашать обезличенные данные кандидатов за пределами программы.
4. Сообщать мейнтейнеру, если не успеваете сделать ревью в оговорённый срок.
