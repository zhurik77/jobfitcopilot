## Проблема: 23 часа на 80 резюме — это норма?

Представьте: вы открываете вакансию Senior Python Developer. Через час — 47 откликов. К вечеру — 124. HR-менеджер открывает каждое резюме, читает, сравнивает с требованиями, ставит пометку. На одно резюме уходит 3–5 минут. На 80 резюме — 4–6 часов чистого времени. Если повезло и кандидатов 200+ — это два полных рабочих дня только на первичный скрининг.

По данным LinkedIn, рекрутер тратит в среднем 23 часа на закрытие одной позиции, из которых 60% уходит на просмотр и оценку резюме. При этом до 75% откликов не соответствуют формальным требованиям вакансии.

HR-инструменты рынка решают эту проблему ровно наполовину. ATS (Applicant Tracking Systems) вроде Greenhouse или Lever автоматизируют воронку, но не анализируют содержание. Крупные HR-tech платформы предлагают встроенный AI-скрининг, но он работает как чёрный ящик: вы видите только процент совпадения, но не можете понять, почему кандидат не подошёл.

Мы решили построить инструмент, который:

- Работает прямо в браузере на странице вакансии
- Не отправляет данные на сторонние серверы
- Показывает не просто процент, а построчную аргументацию
- Стоит копейки — вы платите только за токены вашей LLM
- Открыт полностью — весь исходный код на GitHub

Так родился **Job Fit Copilot**.

## Решение: Chrome-расширение с локальным AI

Job Fit Copilot — это open-source Chrome-расширение (Manifest V3), которое анализирует соответствие резюме требованиям вакансии прямо в браузере. Вы открываете вакансию на hh.ru, LinkedIn или Upwork, загружаете резюме кандидата (или своё) — и через 20 секунд получаете детальный ATS-отчёт.

Ключевая архитектурная идея: **вся обработка идёт через API выбранной LLM напрямую из расширения**. Никакого бэкенда, никакого прокси, никакого сбора данных. Пользователь вводит свой API-ключ — и трафик идёт напрямую к провайдеру (DeepSeek, OpenAI, Anthropic, NVIDIA NIM).

```
┌──────────────┐     ┌─────────────────────┐     ┌──────────────┐
│  Chrome Ext  │────▶│  Server (Node.js)    │────▶│  SQLite DB   │
│  (content)   │     │  ┌─────────────────┐ │     └──────────────┘
└──────────────┘     │  │  MCP Server     │ │     ┌──────────────┐
                     │  │  REST API       │ │────▶│  FastAPI     │
┌──────────────┐     │  │  Autopilot      │ │     │  Custom LLM  │
│  Web Panel   │────▶│  │  FSM Engine     │ │     └──────────────┘
│  (React)     │     │  └─────────────────┘ │     ┌──────────────┐
└──────────────┘     │  WebBridge (Browser) │────▶│  hh.ru /     │
                     └─────────────────────┘     │  LinkedIn     │
                                                 └──────────────┘
```

### Почему расширение, а не сайт?

Расширение имеет доступ к DOM-дереву страницы вакансии. Это значит, что мы можем извлечь структурированные данные: название должности, требования, обязанности, ключевые слова — без парсинга HTML вручную. Content script расширения читает страницу, извлекает структуру вакансии и передаёт в side panel, где и происходит анализ.

Пользовательский опыт выглядит так:

1. Открываете вакансию на hh.ru/LinkedIn/Upwork
2. Нажимаете Ctrl+B — открывается боковая панель Job Fit Copilot
3. Вставляете текст резюме или выбираете из сохранённых
4. Получаете ATS-отчёт с разбивкой по факторам, скорингом и рекомендациями

## Ключевые технические решения

### 1. Алгоритм скоринга

Сердце Job Fit Copilot — скоринг-движок, который оценивает резюме по шести факторам:

| Фактор | Вес | Что оценивает |
|--------|-----|---------------|
| **Hard Skills** | 30% | Техническое соответствие: стек, инструменты, технологии |
| **Experience** | 25% | Релевантность опыта: проекты, индустрия, грейд |
| **Education** | 10% | Базовое соответствие по образованию и сертификациям |
| **Soft Skills** | 10% | Коммуникация, лидерство, работа в команде |
| **Culture Fit** | 10% | Ценности, формат работы, ожидания |
| **Overall** | 15% | Интегральная оценка: насколько кандидат вписывается в контекст |

Каждый фактор оценивается LLM с детальной аргументацией. Итоговый score — взвешенная сумма с нормализацией под 100. В отчёте видно не только цифру, но и конкретные строки из резюме и вакансии, на основе которых сделан вывод.

### 2. Autopilot и FSM Engine

Одна из уникальных фич — **Autopilot**: агентный режим, в котором Copilot самостоятельно анализирует несколько резюме подряд, сохраняет результаты и строит сравнительную таблицу. Под капотом — конечный автомат (FSM) с состояниями:

```
IDLE → ANALYZING → EVALUATING → REPORTING → IDLE
         ↓
      ERROR → IDLE
```

FSM гарантирует, что каждый этап обработки завершается корректно, а при ошибке — возвращается в исходное состояние без потери данных.

### 3. Bulk ATS

Функция массового анализа: загружаете ZIP с 20 резюме — получаете CSV-таблицу со скорами по каждому кандидату. Реализовано через очередь с параллельной обработкой (до 3 одновременных запросов к API LLM), чтобы не превысить rate limit провайдера.

### 4. MCP Server и FastAPI бэкенд

В версии 0.6.0 мы добавили MCP (Model Context Protocol) сервер — это позволяет AI-агентам (Claude, Cursor, Copilot) взаимодействовать с Job Fit Copilot программно. Агент может запросить ATS-анализ через MCP-инструменты, не открывая браузер.

OpenAI-совместимый LLM-ендпоинт (кастомный) работает как прокси-слой для сложных запросов: многопоточная генерация, кэширование результатов, агрегация метрик.

## Тестирование: 235 тестов, никаких фреймворков

Мы приняли нестандартное решение: **весь тестовый стек — на чистом `node:test`**. Без Jest, без Mocha, без Chai. Только встроенный модуль Node.js.

```javascript
const test = require('node:test');
const assert = require('node:assert');

test('score calculation with edge weights', () => {
  const result = calculateScore({
    hardSkills: 85,
    experience: 70,
    education: 60,
    softSkills: 80,
    cultureFit: 75,
    overall: 82
  });
  assert.strictEqual(result.total, 76.75);
  assert.ok(result.breakdown.hardSkills.weight === 0.3);
});
```

Почему?

- **Нулевые зависимости** для тестового раннера — меньше уязвимостей, меньше багов в toolchain
- **Скорость**: `node --test` запускает 235 тестов за 1.2 секунды
- **Простота**: любой разработчик с Node.js может запустить тесты без установки дополнительных пакетов
- **CI-дружественность**: `npm test` работает из коробки в GitHub Actions

Наш CI (`.github/workflows/ci.yml`) гоняет линтер и тесты на каждый push. `release.yml` блокирует публикацию тега при любом провале. Ручной чек-лист перед релизом больше не нужен.

Тесты покрывают:

- Расчёт скоринга с разными весами (включая edge cases: все нули, все сотни, отрицательные значения)
- Экранирование HTML в отчётах
- Формирование ATS-отчётов с разными наборами данных
- Валидацию структуры отчёта
- Обработку пустых и некорректных входных данных

## Open Source: почему мы открыли код

Решение открыть исходный код было осознанным. На рынке есть десятки AI-инструментов для HR, но все они:

- Закрытые (невозможно проверить, как работает алгоритм)
- Дорогие (от $29/мес за базовый тариф)
- Привязаны к конкретному провайдеру AI
- Собирают данные пользователей

Мы пошли другим путём:

- **Полная прозрачность**: любой может проверить, какие данные отправляются в LLM
- **BYOK (Bring Your Own Key)**: пользователь платит только за свои токены
- **Приватность по архитектуре**: данные не покидают браузер пользователя
- **Сообщество**: расширение развивается силами сообщества, а не корпорации

### Наши цели

- **500 звезд на GitHub** — первый рубеж, который покажет, что проект востребован
- **50 форков** — сообщество, которое самостоятельно добавляет адаптеры для новых сайтов
- **10 контрибьюторов** — регулярно вносящих код

## Как начать пользоваться

```bash
git clone https://github.com/zhurik77/jobfitcopilot.git
```

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. Нажмите «Загрузить распакованное расширение»
4. Выберите папку репозитория
5. Откройте любую вакансию на hh.ru — и нажмите Ctrl+B

Поддерживаемые LLM-провайдеры:

- **DeepSeek V4 Flash** — оптимальный баланс цена/качество
- **GLM-5.2** — лучший для китайского рынка
- **GPT-4.1** — максимальное качество анализа
- **Claude Sonnet 4.6** — лучший для длинных контекстов
- **NVIDIA NIM** — для корпоративных клиентов
