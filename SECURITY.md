# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.5.x   | ✅        |
| < 0.5   | ❌        |

## Reporting a Vulnerability

Если вы нашли уязвимость, **не открывайте публичный issue**. Напишите на
macuniverse.it@gmail.com (или через приватный advisory на GitHub:
Security → Report a vulnerability). Ответ — в течение 72 часов.

Что полезно приложить:
- шаги воспроизведения / минимальный пример;
- затронутые файлы и строки;
- возможное влияние (утечка данных, инъекция, обход одобрения отправки).

## Scope

- код расширения (`manifest.json`, `background.js`, `sidepanel/`, `content-scripts/`, `options/`);
- MCP/REST-сервер (`server/src/`);
- сайт и документация (`site/`, `docs/`).

Панель и сервер слушают только `127.0.0.1` и не должны быть доступны из
сети — если нашли способ обращения к ним извне, это тоже уязвимость.

## Что не в scope

- уязвимости самого hh.ru или других job-бордов;
- атаки, требующие физического доступа к машине пользователя;
- спам/социальная инженерия против работодателей.
