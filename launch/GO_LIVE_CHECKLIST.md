**URL to post:** https://news.ycombinator.com/submit

**Title:**
> Show HN: Open-source AI Chrome extension for ATS resume analysis (555+ tests)

**URL:**
> https://github.com/zhurik77/jobfitcopilot

**First comment (post after submission):**
```
I built this because I was tired of manually comparing resumes to job descriptions.
Existing tools were expensive SaaS or closed-source with questionable data practices.

What it does:
- Paste any job description + your resume → get a detailed fit score
- ATS audit → see what recruiters' systems see
- Cover letter generator → one click, multiple tones
- Multi-resume comparison → pick your best version
- Works on LinkedIn, hh.ru, Upwork

Tech:
- Chrome Manifest V3 (side panel, content scripts, service worker)
- Multiple LLM providers: OpenAI, Anthropic, DeepSeek, NVIDIA NIM
- 555+ tests with node:test (no frameworks)
- Full i18n (English + Russian)
- MIT license

Privacy: No data collection. No tracking. No accounts. You bring your own API key.

Looking for HR experts to help calibrate the AI scoring!
https://github.com/zhurik77/jobfitcopilot
```
